# Work Habbits v1.6.0

Posture and hand reminders now reset after time away, so you can return from a break with fresh timers.

## Changes

- After 15 minutes away, start a fresh sitting or standing session in your current posture. This also works when you lock the screen. Daily totals and scores are preserved.
- Reset both hand timers after two minutes without typing or clicking, even before reminders are due. The default 20-second rest still resets the short timer alone.
- Scrolling, pointer motion, and touchpad contact leave hand rests running. On Wayland, the reader counts physical button events.

## Upgrade

Run `./install.sh` as your normal user. The updated extension loads at your next login. History and reminder intervals are preserved.

## Validation

Automated tests cover the rest thresholds, returning after a lock, and preserving saved totals. The isolated GNOME test uses generated input and simulated desk status. Physical input and desk behavior still need a desktop check.
