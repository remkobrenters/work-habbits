# Work Habbits v1.5.0

This release merges the open Ruff and Bleak dependency updates. The extension's reminders, settings, and history format are unchanged from v1.4.0.

## Changes

- Update Ruff from 0.17.3 to 0.17.4 for development lint and formatting checks.
- Update Bleak from 3.0.2 to 3.1.0 for optional Bluetooth desk support. The existing `dbus-fast==5.2.0` pin satisfies Bleak's new Linux minimum of 4.0.0.

## Upgrade

Run `./install.sh` as your normal user. If you use a Bluetooth desk, the installer updates the optional Bluetooth environment. Settings and history are preserved. The new extension metadata loads at your next login.

## Validation

The full quality gate, dependency audit, source package, and isolated GNOME Shell checks passed with the updated dependencies. Bluetooth movement tests use simulated hardware; physical desk behavior still needs a supervised check.
