# Work Habbits v1.2.0

This release replaces the single top-bar countdown with Posture and Hands progress bars, bounds the red phase to two penalties per round, and swaps reminder banners for a configurable sound.

## Changes

- Show **Posture** and **Hands** side by side in the top bar: a label with a thin bar that fills toward the next change and a smaller, softer time. Green is steady, orange blinks slowly when a change is due, red blinks fast when you are too late, and gray means unavailable. Optional standing and keyboard icons follow their bar's color; the sitting icon is gone.
- Bound the red phase. Orange is a silent warning (2 minutes for posture, 1 for hands). Red lasts at most 10 active minutes: a penalty halfway, another at the end, then that timer starts a new round. An ignored reminder never charges more than two misses per round.
- Rework snoozes for the new flow. Snoozing takes back penalties already charged in the round and holds the reminder at a steady orange. If you are still working when the snooze runs out, a fresh red window counts both penalties twice by default; locking, leaving or prolonged idle time cancels the doubling.
- Remove reminder banners. In red a sound plays and repeats every 15 seconds by default (once, every 15 or 30 seconds, or every minute) while you keep working. Choose one of three bundled sounds, preview it, and set its volume (70% by default) in Settings. Idle, locked, paused and snoozed time stays silent, and GNOME's Do Not Disturb mutes the sound while the bars keep blinking.
- Bundle the notification sounds in `extension/sounds/` with credits in `THIRD_PARTY_NOTICES.md` and hashes in `docs/audio-provenance.json`. The sounds are Pixabay content, not MIT.
- Replace the outdated README screenshots with labeled renderings of the top bar and menu, regenerated with `node scripts/render_previews.mjs`.
- Include the upstream Ruff update to 0.17.3 and regression coverage for the red window, snoozes, upgrades from v1.1 records, panel rendering, sound scheduling and Do Not Disturb.

## Upgrade

Install the new prerequisite for reminder sounds:

```bash
sudo apt install gstreamer1.0-plugins-base-apps
```

Download and extract the source archive, then run `./install.sh` from an active local GNOME desktop terminal. For a Bluetooth desk, use `./install.sh --bluetooth`. Existing preferences and daily history are preserved. Log out and back in to load the new extension; on Xorg, **Alt+F2**, `restart`, Enter also works.

Settings changes:

- **Show reminder notifications** and the three **Further … minutes per miss** settings are removed. The new **Red warning window** (10 minutes) replaces the per-miss intervals.
- The orange warning defaults for standing up and sitting down change from 5 to 2 minutes. Values you changed yourself are kept.
- New: **Show icons in the top bar** (off), and a **Sound** group with on/off (on), sound choice (Notification 3), volume (70%) and repeat (every 15 seconds).

Snoozes saved by v1.1 in their final "broken" state are dropped on load, and timers already past the new red window start a new round without charging again.

## Validation and compatibility

The release workflow runs style/security lint, schema and syntax checks, automated behavioral tests, dependency auditing, and source packaging before publication. `pip-audit` found no known vulnerabilities in the runtime or development requirements; all runtime dependencies are at their latest releases. Sound playback was verified by decoding all three bundled sounds with `gst-play-1.0`; the top bar, blinking, sound and Do Not Disturb muting still need a live desktop check on Ubuntu 24.04 / GNOME Shell 46 / Xorg before tagging.

GNOME 46–50 compatibility remains as documented in the README. Keyboard/mouse counts require Xorg. The README images are renderings with sample data, not desktop screenshots.
