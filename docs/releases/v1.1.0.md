# Work Habbits v1.1.0

This release fixes Bluetooth connections to desks already connected through GNOME or bluetoothctl, restores reminder snoozing, and makes the dashboard more compact.

## Changes

- Reuse the configured desk's known BlueZ device, including existing connections that no longer advertise. Keep specific connection errors visible and explain when height data is still pending.
- Restore **Snooze — leaving soon** for due posture and hand reminders. Defaults are 15 minutes for posture and 10 minutes for hands, with configurable grace and penalty behavior. Snoozes persist across extension restarts.
- Forgive held snooze misses when the computer locks or the local session becomes inactive. Prolonged inactivity also forgives them; inactive time never advances penalty grace.
- Show sitting and standing panel silhouettes in the existing reminder colors, with tighter spacing around the countdown.
- Narrow the menu, move Tracking to Settings with an explanation, and show manual movement breaks only in fixed-desk mode. Existing movement-break history remains intact.
- Hide the normal history footer while retaining read/save error messages. Add an aligned **View repository** link at the bottom of Settings.
- Add an explicit, one-time Workspace Monitor history importer with a preview, private backups, overlap handling, and a journal that prevents repeat imports.
- Include the upstream Ruff update to 0.17.2 and regression coverage for Bluetooth resolution, snoozes, persistence, installation, and dashboard behavior.

## Upgrade

Download and extract the source archive, then run `./install.sh` from an active local GNOME desktop terminal. For a Bluetooth desk, use `./install.sh --bluetooth`. Existing preferences and daily history are preserved.

Reload GNOME Shell to load updated JavaScript and icon assets: on Xorg, press **Alt+F2**, type `restart`, and press Enter; on Wayland, log out and back in.

Workspace Monitor imports are optional and never run automatically. Follow the README's preview and backup instructions before applying an import. Working-time fields and original snooze snapshots remain in the backup; they are not mapped into imported records.

## Validation and compatibility

The release workflow runs style/security lint, schema and syntax checks, automated behavioral tests, dependency auditing, and source packaging before publication. A live check verified Bluetooth height reporting on Ubuntu 24.04 / GNOME Shell 46 / Xorg. Desk movement was not exercised in the live release check; movement tests use simulated hardware.

GNOME 46–50 compatibility remains as documented in the README. Keyboard/mouse counts require Xorg. The README dashboard screenshots are labeled as the earlier v1.0.0 layout.
